# BYD Sales Consultant Toolkit

**Created & Designed by Kevin Lim Fung Yen** — EV Supreme In-House Trainer

A macOS-style toolkit that helps BYD Malaysia sales consultants build branded offer posters, compare models, show trade-in impact, and track leads — all in seconds.

## Features

- **Offer Studio** — pick a model, set OTR price, cash/extra rebates, financing and validity, and instantly render a branded 9:16 offer poster (downloadable PNG).
- **One-tap WhatsApp share** — auto-generates a ready Malay offer message with the consultant's contact.
- **Compare Models** — put 2–3 models side by side (price, specs, deposit, monthly) to help undecided buyers.
- **Trade-in Helper** — show how an old-car trade-in lowers the monthly payment.
- **Lead Tracker** — capture customers, set follow-up dates, get reminders for overdue follow-ups (stored on-device).
- **Model & Price Library** — edit the 2026 lineup prices & specs that feed every tool.

## Lineup (2026, editable)

BYD ATTO 2 · ATTO 3 (Ultra / Premium / Performance) · M6 · SEAL 6 · SEAL · SEALION 7 (Dynamic / Premium / Performance)

## Tech

Single self-contained HTML file. No build step, no backend — data is stored locally in the browser (localStorage). Open `index.html` in any browser, or host it as a static site.

## Note

- Prices & specs are baseline estimates seeded from public BYD Malaysia dealer sites and are **editable** in the Model & Price Library.
- Financing figures are estimates only, subject to bank approval.
